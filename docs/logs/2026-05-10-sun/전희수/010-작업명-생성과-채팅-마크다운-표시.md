## 작업 목적

- 작업 모드에서 긴 사용자 원문이 그대로 작업 제목으로 보이지 않도록 제목 생성 흐름을 분리한다.
- 채팅 답변의 마크다운 문법을 일반 텍스트가 아니라 읽기 쉬운 서식으로 표시한다.
- 파일 저장 성공 뒤 이전 실패 시도 때문에 작업이 계속 차단됨으로 남는 상태 판정을 보정한다.

## 변경 요약

- 작업 생성 요청의 `title`을 선택값으로 바꾸고, 서버에서 모델 기반 작업 제목을 생성하도록 했다.
- 제목 생성 실패 시에도 로컬 경로나 긴 원문이 보드 제목으로 새지 않도록 fallback 제목을 정리했다.
- 채팅 assistant 메시지에 GFM 기반 마크다운 렌더링을 적용했다.
- 작업 실행 결과에 파일/터미널 실패가 있어도 이후 파일 저장 성공이 있으면 완료 상태로 반영되도록 상태 판정을 보강했다.

## 결정, 이슈, 리스크

- 작업 상세 설명과 실행 지시는 사용자 원문을 유지하고, 보드 제목만 별도 요약값을 사용한다.
- 파일 저장은 성공했지만 앞선 실패 시도가 남아 있는 경우에는 마지막 파일/터미널 관련 결과를 기준으로 차단 여부를 판단한다.
- dev 환경의 토큰 만료와 컨테이너 재시작 중 WebSocket 연결 오류가 콘솔에 남을 수 있으나, 최종 실행 흐름은 ready와 DB 상태로 재확인했다.
