## 작업 목적

세션에서 사용하는 기본 제공 에이전트와 직접 만든 에이전트를 서버 프로필과 지침 묶음으로 저장하고, 채팅/작업 실행에서 선택한 담당 에이전트의 지침을 컨텍스트로 사용할 수 있게 한다.

## 변경 요약

- 기본 제공 에이전트 템플릿 5종을 서버에서 관리하도록 추가했다.
- 세션별 에이전트 프로필, 지침 묶음, 지침 문서 저장 테이블과 저장소를 추가했다.
- 세션 생성 시 `기본 제공 에이전트`를 선택하면 첫 메시지 수락 후 세션 에이전트를 자동 생성하도록 연결했다.
- 2차 사이드바가 세션 진입 시 서버 에이전트 목록을 다시 불러와 표시하도록 보강했다.
- 직접 만든 에이전트도 서버 프로필로 생성되도록 API와 화면 저장 흐름을 연결했다.
- 작업 실행 컨텍스트에 담당 에이전트 프로필과 지침 문서가 포함되도록 HTTP/WS 실행 경로를 보강했다.

## 결정, 이슈, 리스크

- 내부 실행용 worker는 사용자 작업 담당자나 보드 카드로 노출하지 않는다.
- 기본 제공 에이전트는 세션 생성 직후 로컬 UI 상태에도 즉시 반영하고, 새로고침 시 서버에서 다시 hydrate한다.
- 기본 제공 에이전트 세션에서는 실행 중 metadata update가 거절될 수 있어 세션 표시 메타데이터 저장을 생략했다.
- 에이전트 프로필 수정 전체 저장은 아직 지침 문서 저장 중심이다. 프로필 이름/설명 수정까지 서버에 반영하는 API는 후속 보강 대상이다.
