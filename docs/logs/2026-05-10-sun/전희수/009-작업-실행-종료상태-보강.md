- 작업 목적: 작업 보드에서 시작한 실행이 장시간 진행 중으로 남거나, 실행 도구 실패가 완료처럼 보이는 상황을 줄인다.
- 변경 요약:
  - 작업에 연결된 실행에는 별도 반복 한도를 기본 적용하도록 했다.
  - 모델 도구 호출이 반복 한도 안에서 최종 답변을 만들지 못하면 TaskRun을 실패로 종료하도록 했다.
  - 연결 작업의 실행이 실패하거나 파일/터미널 실행 도구 실패를 포함한 채 완료되면 작업을 차단 상태로 전환하고 시스템 댓글을 남기도록 했다.
