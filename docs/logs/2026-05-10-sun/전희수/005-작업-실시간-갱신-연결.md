## 작업 목적

- 작업 상태와 댓글 변경이 열린 브라우저의 작업 보드에 즉시 반영되도록 연결합니다.
- 작업 보드의 최종 표시 기준을 REST 재조회에만 의존하지 않도록 보강합니다.

## 변경 요약

- 인증된 WebSocket 연결을 사용자 단위 작업 토픽에 구독시켰습니다.
- 작업 생성, 상태 변경, 보관/복구, 라벨 교체, 댓글 추가 후 `work.created`, `work.updated`, `work_comment.created` frame을 발행합니다.
- 프론트 실시간 provider가 작업 frame을 작업 store로 넘기도록 연결했습니다.
- 작업 store가 실시간 frame으로 작업 목록과 댓글 목록을 갱신하도록 처리했습니다.

## 결정, 이슈, 리스크

- 이번 범위는 작업 리소스 변경 이벤트입니다. TaskRun 종료에 따른 작업 실행 이력 갱신은 기존 TaskRun 이벤트와 작업 재조회 보강을 함께 정리해야 합니다.
- 사용자 단위 토픽은 같은 사용자 브라우저의 모든 열린 세션에 frame을 보냅니다. 프론트 store는 `sessionId`로 보드 표시 대상을 구분합니다.
