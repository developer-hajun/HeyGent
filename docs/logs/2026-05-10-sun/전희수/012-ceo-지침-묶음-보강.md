## 작업 목적

세션의 메인 에이전트가 단일 기본 지침만 갖는 문제를 보완하고, 기본 제공 에이전트 생성 흐름에서 메인 에이전트 지침과 세션 에이전트 지침이 함께 관리되도록 정리한다.

## 변경 요약

- 메인 에이전트 템플릿에 기본 지침, 작업 루프 지침, 역할 성향 지침, 도구 사용 지침을 함께 포함했다.
- 기존 세션의 메인 에이전트 프로필을 조회할 때 누락된 지침 문서가 있으면 현재 템플릿 기준으로 보강되도록 했다.
- 작업 담당자 지침에서 내부 실행 단위가 사용자에게 보이는 담당자로 노출되는 표현을 제거했다.
- 메인 에이전트 지침 화면이 지침 문서를 우선 표시하고 저장하도록 정리했다.
- 세션 생성과 에이전트 설정 화면에서 현재 흐름에 필요하지 않은 고급 연결 설정 입력을 줄였다.

- 사용자에게 보이는 작업 담당자는 메인 에이전트 또는 세션에 등록된 에이전트로 제한한다.
- 내부 실행 단위는 작업 보드의 담당자로 직접 승격하지 않는다.
