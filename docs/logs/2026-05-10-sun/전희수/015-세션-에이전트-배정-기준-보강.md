## 작업 목적

- CEO가 세션 에이전트에게 작업을 맡길지 판단하는 기준을 명확히 한다.
- 내부 worker 실행과 사용자에게 보이는 세션 에이전트 작업 배정을 구분한다.

## 변경 요약

- CEO 기본 지침에 세션 에이전트 후보 비교, 전문성 기준, 작은 작업 직접 처리 기준을 추가했다.
- 작업 루프 지침에 하위 작업 분리 기준과 병렬 처리 기준을 추가했다.
- 런타임 프롬프트와 `session_agent_task` 도구 설명에 같은 배정 기준을 반영했다.

## 결정 / 이슈

- 코드 분기 기반 의도분류는 추가하지 않았다.
- 배정 판단은 현재 세션 에이전트 후보와 작업 맥락을 보고 모델이 결정하도록 유지했다.
- `worker.default`는 사용자에게 보이는 작업 담당자가 아니라 내부 병렬 실행 단위로만 남긴다.
