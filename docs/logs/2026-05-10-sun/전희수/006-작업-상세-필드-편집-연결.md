## 작업 목적

- 작업 상세 제목과 설명을 기본 읽기 모드로 보여주고, 클릭했을 때만 편집하도록 바꿉니다.
- 제목/설명 변경이 서버 작업 데이터와 실시간 보드 갱신에 반영되도록 연결합니다.

## 변경 요약

- `POST /work/{workId}/update-fields` API를 추가했습니다.
- 작업 저장소에 제목/설명 부분 갱신 메서드를 추가했습니다.
- 프론트 작업 API와 작업 store에 `updateFields` 명령을 추가했습니다.
- 작업 상세의 제목/본문을 읽기 모드와 편집 모드가 분리된 인라인 편집 UI로 바꿨습니다.

## 테스트 또는 확인 내용

- `python -m compileall app`
- `python -m pytest tests\api\test_tasks_runtime.py tests\api\test_ws_commands.py tests\domain\test_work_service.py tests\storage\test_postgres_durable_contracts.py`
- `npm run build`
- `npm run lint`
- `docker compose up -d --build ai`
- `GET http://localhost:8000/ai/api/v1/ready`
- 브라우저에서 `TASK-2` 상세를 열고 제목을 `주식 뉴스 조사`로 수정했습니다.
- 수정 후 상세 패널과 서버 작업 목록에서 변경된 제목이 반영되는 것을 확인했습니다.

## 결정, 이슈, 리스크

- 제목은 빈 값 저장을 막고, 설명은 빈 값 저장이 가능합니다.
- 상세 속성 중 담당자, 라벨, 하위 작업, 차단 관계는 아직 서버 명령 연결이 필요합니다.
