# 작업 보드 협업 표면 확장

- 날짜: 2026-05-10
- 작성자: 전희수
- 관련 브랜치 또는 PR: `AI-feat/subagent-fe-connection`

## 작업 목적

작업 보드에서 작업의 구조, 차단 관계, 산출 문서, 결과물, 사용자 확인 요청을 한 화면에서 추적할 수 있도록 서버 계약과 프론트 상세 화면을 확장한다.

## 변경 요약

- 작업에 부모 변경, 하위 작업 생성, 관계 제거 API를 추가했다.
- 작업 문서, 문서 이력, 결과물, 확인 요청을 저장/조회/수정할 수 있는 DB 테이블과 HTTP API를 추가했다.
- 작업 실행 컨텍스트 미리보기에 댓글, 문서, 결과물, 확인 요청 요약을 포함하도록 확장했다.
- 작업 보드 상세 패널에 부모/하위 작업, 문서, 결과물, 확인 요청 탭을 추가했다.
- 명시적 작업 종료 상태가 없는 실행 완료는 자동 완료하지 않고 검토 상태로 남기는 정책에 맞춰 도메인 테스트를 정리했다.
