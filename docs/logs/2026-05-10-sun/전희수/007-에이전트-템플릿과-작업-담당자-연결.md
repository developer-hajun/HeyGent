## 작업 목적

- 세션에서 기본 제공 에이전트를 빠르게 추가할 수 있게 합니다.
- 작업 보드에서 바꾼 담당 에이전트가 서버 작업 데이터와 다음 실행 컨텍스트에 반영되게 합니다.

## 변경 요약

- 새 에이전트 추가 대화상자에 기본 제공 에이전트 선택 항목을 추가했습니다.
- 기본 제공 에이전트를 선택하면 현재 세션에 중복되지 않는 이름으로 즉시 추가되도록 했습니다.
- 작업 생성 요청과 담당자 변경 API에 `assigneeAgentId`를 연결했습니다.
- 작업 보드의 담당자 선택을 서버 저장 명령으로 연결했습니다.
- 작업 실행 프롬프트에 작업 번호, 담당자, 작업 요약이 포함되도록 보강했습니다.
