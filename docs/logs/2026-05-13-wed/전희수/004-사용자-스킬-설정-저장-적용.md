## 작업 목적

- 내장 스킬을 DB catalog로 동기화하고 사용자별 사용 여부와 에이전트별 적용 범위를 실제 실행 경로에 반영한다.
- 설정 화면에서 사용 중/미사용 스킬을 관리하고 상세 내용을 확인할 수 있게 한다.

## 변경 요약

- `ai_skill_catalog`, `ai_user_skill_settings`, `ai_agent_skill_settings` 테이블과 migration을 추가했다.
- 앱 시작 시 `app/skills/**/SKILL.md`를 catalog에 동기화하고 사용자별 enabled 상태를 lazy 생성한다.
- 세션 실행 입력에 사용자/에이전트 기준 effective skill 목록을 주입해 prompt catalog와 runtime tool 노출을 제한한다.
- `skills.read_file` runtime tool을 추가해 선택된 스킬 폴더 안의 비밀 파일이 아닌 텍스트 보조 파일만 상대 경로로 읽게 했다.
- 설정 스킬 탭을 `@dnd-kit` 기반 사용 중/미사용 컬럼과 저장 버튼, 상세 모달 구조로 바꿨다.
- 에이전트 스킬 탭은 실제 사용자 catalog를 조회하고 상세 모달에서 설명, 파일 목록, 원문을 확인하도록 연결했다.

## 결정 / 이슈

- 스킬은 폴더 단독이 아니라 `SKILL.md` 기준으로 catalog row를 만든다.
- 사용자별로 스킬 원문을 복사하지 않고 catalog를 참조하는 enabled 설정을 저장한다. 이렇게 해야 내장 스킬 수정 시 사용자 row와 원본이 갈라지지 않는다.
- 스킬 보조 파일은 일반 파일 tool이나 cloud shell 실행으로 열지 않고, 스킬 폴더 내부 상대 경로 전용 tool로 제한한다.
- 개발용 로그인 버튼은 화면 레이어가 일반 click을 가로채는 기존 문제가 있어 테스트 자동화에서 JS click 우회가 필요했다.
