## 작업 목적

작업 보드에서 프로젝트 개념을 제외한 대신 라벨을 작업 분류 축으로 사용할 수 있도록 기본 라벨, 색상, 상세 선택, 필터 흐름을 추가한다.

## 변경 요약

- 작업 보드 모델에 10개 기본 라벨과 색상 정보를 추가했다.
- 작업 상세에서 라벨 검색, 선택, 색상 지정 새 라벨 생성이 가능하도록 했다.
- 목록과 보드 카드에 선택된 라벨 칩을 표시했다.
- 필터 팝오버에 라벨 필터를 추가하고 내부 스크롤로 높이가 과도하게 늘어나지 않게 했다.
- 작업 상세의 댓글 탭 문구를 채팅이 아니라 댓글 기준으로 바꿨다.
- 용도가 불명확한 표준/계획 모드를 제거하고, 작업 분류는 라벨로만 표현하도록 정리했다.
- 중복으로 보이던 다음 조치와 live 표시 뱃지를 제거했다.
- 우선순위는 색 배경 칩 대신 색 아이콘과 중립 텍스트로 낮추고, 라벨은 보드와 상세에서 같은 중립 pill 스타일로 통일했다.

## 결정, 이슈, 리스크

- 라벨은 프로젝트보다 가벼운 작업 분류 축으로 둔다.
- 작업 상세 댓글은 일반 채팅이 아니라 실행 시 참고할 작업 메모로 취급한다.
- 현재 라벨 생성과 작업 라벨 변경은 로컬 상태 저장 기준이며, 서버 API와 WebSocket 이벤트 계약은 별도 연결이 필요하다.
