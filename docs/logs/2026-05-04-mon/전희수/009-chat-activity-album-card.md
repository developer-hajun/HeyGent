## 작업 목적

답변 활동 상단 영역이 다음 카드 일부를 보여주는 가로 목록처럼 보이지 않게 하고, 한 번에 하나의 답변 활동만 보여주는 앨범형 카드로 정리한다.

## 변경 요약

- 답변 활동 상단 영역에서 여러 카드를 한 줄에 렌더링하던 구조를 제거했다.
- 현재 선택된 답변 활동 카드 하나만 렌더링하도록 변경했다.
- 첫 번째 답변 활동에서는 왼쪽 이동 버튼을 숨기고, 마지막 답변 활동에서는 오른쪽 이동 버튼을 숨긴다.
- 좌우 버튼은 스크롤 이동이 아니라 선택된 답변 활동 인덱스를 바꾸는 방식으로 동작한다.
- 긴 질문 제목은 공백을 정리한 뒤 일정 길이를 넘으면 `...`으로 줄여 카드 바깥으로 넘치지 않게 했다.

## 결정, 이슈, 리스크

- 답변 활동 카드는 상세 펼치기 버튼이 아니라 해당 답변 위치로 이동하는 버튼으로 유지한다.
- 현재 브라우저 검증 세션에는 답변 활동이 1개뿐이라 좌우 버튼이 둘 다 숨겨지는 케이스를 확인했다.
- Vite 빌드의 기존 chunk size warning은 남아 있으나 이번 변경과 직접 관련된 실패는 아니다.
