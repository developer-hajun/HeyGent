## 작업 목적

- 채팅 세션 설정과 서브에이전트 목록을 기존 좌측 사이드바 옆 2차 사이드바로 분리합니다.
- 펼친 좌측 사이드바의 세션 클릭 동작을 채팅 화면 이동으로 통일합니다.

## 변경 요약

- `RightPanel` 플로팅 탭을 앱 레이아웃에서 제거하고 세션 워크스페이스 사이드바로 대체했습니다.
- 세션 워크스페이스를 세션 이름 인라인 편집, 연결 상태, 채팅/시각화 메뉴와 CEO/에이전트 섹션 중심으로 재구성했습니다.
- 서브에이전트는 메뉴 탭이 아니라 2차 사이드바 하단 절반 섹션으로 분리했습니다.
- 메인 에이전트와 에이전트 섹션을 누르면 채팅 영역 대신 오른쪽 전체 작업면이 열리도록 변경했습니다.
- 상단 `목표` 메뉴는 제거하고 `CEO` 섹션 아래 메인 에이전트 row의 편집 진입점으로 통합했습니다.
- 기존 `서브에이전트` 섹션과 작업면 표기는 사용자 노출 문구에서 `에이전트`로 정리했습니다.
- CEO 아래 에이전트 섹션 헤더는 영문 `AGENT`로 표시되도록 정리했습니다.
- 오른쪽 작업면은 페이지형 간격에 맞춰 `p-4 md:p-6`, `space-y-6`, border row/list 중심으로 재구성했습니다.
- 오른쪽 작업면은 모달/오버레이처럼 닫는 `X` 없이 2차 사이드바 라우팅으로 전환되도록 정리했습니다.
- 시각화 메뉴도 2차 사이드바 라우팅 체계에 맞춰 `/session/:sessionId/workspace/visualization` 작업면으로 열리도록 변경했습니다.
- 목표 상세 패널에 새 대화 커스터마이징 값인 에이전트 이름, 호칭, 페르소나와 프롬프트용 목표/성공 기준/제약 입력을 배치했습니다.
- 메인 에이전트 작업면은 `CEO` 맥락에서 에이전트 이름, 호칭, 페르소나, 목표, 성공 기준, 제약을 한 번에 편집하도록 노출합니다.
- 기존 설정 작업면은 제거하고 메인 에이전트 작업면에 이미지 프리셋 좌우 토글과 모델 선택을 통합했습니다.
- 대화 프롬프트 영역은 좌우 4:3으로 나눠 오른쪽에 모델 선택 UI를 배치했습니다.
- 대화 프롬프트 왼쪽 입력은 `대화 목표`, `응답 역할` 행 라벨만 남겨 각 입력의 의미를 구분했습니다.
- 세부사항 입력도 중복 식별자 칸을 제거해 `에이전트 이름`, `호칭`, `성공 기준`, `제약` 라벨만 표시되도록 정리했습니다.
- 세부 지시는 `세부사항`으로 바꾸고 왼쪽 약 1/5 칸에 설명 문구 없는 정사각형 이미지 선택 UI를 세로 중앙 정렬했습니다.
- 메인 에이전트 편집 표는 브라우저 폭이 줄어도 2열을 유지하고 내부 이미지/모델 목록만 축소되도록 반응형 기준을 조정했습니다.
- 2차 사이드바 연결 상태는 `AI 연결 확인 필요`처럼 연결 대상을 드러내고 와이파이/경고 아이콘과 상태색으로 표시합니다.
- 사이드바 로고는 펼친 상태에서 가로형 `logo-no-character.png`, 접힌 상태에서 아이콘형 `onlylogo.png`를 쓰도록 분리했습니다.
- 1차 사이드바 접힘 상태의 세션 채팅 아이콘은 2차 사이드바의 채팅 아이콘과 같은 `MessageSquare`로 통일했습니다.
- 1차/2차 사이드바의 주요 아이콘과 메뉴 글자 크기를 한 단계 키워 접힌 레일과 펼친 메뉴의 밀도를 맞췄습니다.
- 연결 상태 문구는 `AI` 대신 `서버 연결 준비 중`, `서버 연결 확인 필요`처럼 서버 기준 문구로 통일했습니다.
- 서브에이전트 추가/편집 폼에 채택된 스킬과 사용 가능한 스킬 2열 보드를 추가하고 Notion, Samsung Health, Code 예시 스킬을 배치했습니다.
- 스킬 보드는 사용 가능한 스킬을 클릭하거나 채택 영역으로 드래그해 채택할 수 있고, 검색창과 향후 사용자 스킬 추가용 `+` 버튼을 포함합니다.
- 1차/2차 사이드바 expanded 폭을 260px로 키우고 접힘 상태의 사용자 아이콘이 하단에 붙지 않도록 여백을 조정했습니다.
- 서브에이전트는 사이드바 헤더 `+` 하나, row hover 액션 메뉴, 오른쪽 작업면의 추가/편집/삭제 폼으로 정리했습니다.
- 오른쪽 서브에이전트 페이지의 중복 추가 버튼은 제거하고 2차 사이드바 헤더 `+`로 추가 진입점을 통일했습니다.
- 1차/2차 사이드바의 접힘 폭을 48px로 맞추고 상단 펼침 버튼 위치를 정렬했습니다.
- 메인 에이전트와 에이전트 작업면의 영어 내부 라벨을 한국어 라벨과 예시 placeholder로 교체했습니다.
- 세션별 서브에이전트 목록은 새로고침 후에도 유지되도록 직렬화 가능한 값으로 저장합니다.
- 펼친 좌측 사이드바의 세션별 `...` 메뉴와 채팅 아이콘을 제거했습니다.
- 펼친 좌측 사이드바에서 채팅 세션을 클릭하면 해당 채팅으로 이동하면서 1차 사이드바를 자동으로 접습니다.
- 펼친 좌측 사이드바의 `+ 새 대화` 위치는 대화 세션 목록 상단으로 유지했습니다.
- 좌측 사이드바의 활동 패널 버튼을 제거해 채팅 메시지의 진행/완료 상태에서 실행 상세를 열도록 흐름을 정리했습니다.
- 좌측 사이드바와 2차 사이드바의 접힘 상태를 독립적으로 관리하도록 변경했습니다.

  - `목표` 메뉴 클릭 시 오른쪽 전체 작업면이 열리고 별도 오버레이 없이 라우팅됨
  - `채팅` 메뉴 클릭 시 `/session/:sessionId`로 복귀함

  - 메인 에이전트 작업면의 세부사항 왼쪽에 정사각형 이미지 선택 UI가 세로 중앙 정렬됨
  - 1100px 폭에서도 대화 프롬프트/세부사항 표가 2열을 유지하고 이미지 선택 버튼이 칸 안에 표시됨
  - 서브에이전트 섹션은 중복 추가 버튼 없이 헤더 `+`만 표시됨
  - 서브에이전트 추가 화면에서 스킬 검색, 채택된 스킬/사용 가능한 스킬 보드가 표시됨
  - `시각화` 메뉴 클릭 시 `/session/:sessionId/workspace/visualization` 작업면으로 이동함
  - 좌측 사이드바 접힘과 2차 사이드바 접힘이 독립적으로 동작함
  - 실제 로그인 세션이 아닌 테스트 URL에서는 입력창이 비활성화되고 빈 상태 문구가 표시됨

## 결정 / 이슈

- 세션 데이터가 없는 라우트에서는 상세 패널에 빈 상태를 보여줍니다.
- 시각화 화면은 2차 사이드바의 `시각화` 메뉴에서 `/session/:sessionId/workspace/visualization`로 라우팅됩니다.
- 활동 패널은 좌측 사이드바에 직접 노출하지 않고 기존 채팅 진행/완료 상태 진입 흐름을 유지합니다.
