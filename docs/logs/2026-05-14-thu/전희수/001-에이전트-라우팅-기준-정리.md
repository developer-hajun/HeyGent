## 작업 목적

- CEO가 모든 사용자 입력을 받은 뒤 세션 에이전트가 수행할 수 있는 요청을 자연스럽게 맡기도록 라우팅 기준을 낮춘다.
- 세션 에이전트 후보 정보에 이름, 호칭, 할 수 있는 일, 스킬이 드러나게 해 라우팅 판단 근거를 명확히 한다.

## 변경 요약

- CEO 라우팅 프롬프트에서 `명확한 위임 단위`, `가장 적합한 후보` 중심 표현을 `수행할 수 있다고 판단되는 에이전트` 기준으로 변경했다.
- 세션 에이전트 후보 프롬프트 표시를 `이름`, `호칭`, `할 수 있는 일`, `스킬`, `참고 분류` 형태로 정리했다.
- 기본 제공 에이전트에 한국 생활 정보 담당 에이전트를 추가하고 관련 K skill 16개를 기본 연결했다.
- skill 설명 프롬프트도 `설명과 맞으면`보다 `수행할 수 있는 skill` 기준으로 맞췄다.

## 결정 / 이슈

- `role`은 라우팅의 핵심 기준으로 쓰지 않고 `참고 분류`로만 노출한다.
- 실제 실행과 작업 배정은 이름이나 호칭이 아니라 `profileId` 기준으로 유지한다.
- 브라우저 도구 런타임에서 별도 CLI 미설치 경고가 있었지만, 이번 라우팅 검증에는 영향을 주지 않았다.
- 기존 `.gitignore` 변경은 이번 작업과 무관해 커밋에서 제외한다.
