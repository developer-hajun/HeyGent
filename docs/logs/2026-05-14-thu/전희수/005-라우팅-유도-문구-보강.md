## 작업 목적

CEO가 세션 에이전트 후보를 봤을 때 강제 위임이 아니라 자연스럽게 맡길 부분을 먼저 찾도록 라우팅 유도 문구를 보강한다.

## 변경 요약

- CEO 기본 지침에 전문성이 맞는 후보가 있으면 맡길 수 있는 부분을 먼저 찾아보는 문장을 추가했다.
- 런타임 라우팅 지침에도 같은 방향의 문장을 추가했다.
- 기존의 CEO 직접 처리 허용 기준은 유지했다.

## 결정, 이슈, 리스크

- 라우팅 기준은 `전문성이 맞는 후보 확인`과 `독립 작업으로 맡기는 자연스러움`을 함께 본다.
- 에이전트 호출을 강제하지 않고, CEO 직접 처리 가능 문구는 유지했다.
