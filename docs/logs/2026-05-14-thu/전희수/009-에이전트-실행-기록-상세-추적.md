## 작업 목적

- 에이전트 설정의 실행 기록 탭에서 CEO와 서브에이전트 실행 상태, 요청, 위임 입력, 대화 기록, 도구 실행, 결과를 추적할 수 있게 정리합니다.

## 변경 요약

- 실행 기록 상태 색상과 설명을 CEO/서브에이전트 공통 기준으로 통일했습니다.
- 실행 기록 상세에 받은 요청, 맡긴 내용, 돌려준 답변 중심의 대화 흐름을 추가했습니다.
- 저장된 원문 대화와 실행 과정은 기본 접힘 상태로 두어 필요할 때 펼쳐 볼 수 있게 했습니다.
- 돌려준 답변은 진행 요약보다 저장된 마지막 assistant 답변을 우선 표시하도록 정리했습니다.
- 실행 상태는 TaskRun 상세 상태를 우선 사용해 완료된 실행이 준비 중으로 보이지 않게 했습니다.
- 왼쪽 실행 목록의 상태 점 표시는 텍스트 배지로 바꾸고, 배지/시간/ID가 세로로 밀리지 않도록 행 레이아웃을 고정했습니다.
- 상세 조회가 불가능한 내부 이어가기 placeholder는 실행 목록에서 숨기고, 실제 위임 실행은 `K-에이전트 위임 실행`처럼 담당 흐름이 보이게 표시했습니다.
- TaskRun 상세, TaskRun flow, AgentSession 메시지를 조회해 저장된 transcript와 위임 흐름을 표시하도록 연결했습니다.
- 세션 fallback 항목은 TaskRun 상세 조회 대상에서 제외해 불필요한 404 요청을 막았습니다.
- 실행 기록 전용 UI와 타입을 `agentRuns/` 폴더로 분리해 대형 설정 패널 파일의 책임을 줄였습니다.

## 결정 / 이슈

- 서브에이전트의 지속 채팅 세션을 새로 만들지는 않고, 현재 저장되는 TaskRun 단위 transcript를 실행 기록에서 추적하는 방식으로 정리했습니다.
- 저장된 transcript가 없는 실행은 빈 상태 문구로 표시합니다.
