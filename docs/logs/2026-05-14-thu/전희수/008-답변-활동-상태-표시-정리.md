## 작업 목적

답변 활동 패널에서 상태 색상과 실행 주체 구분이 혼동되지 않도록 상태 표기 기준을 통일하고, 사용자가 상태 의미를 바로 확인할 수 있게 한다.

## 변경 요약

- 답변 활동 패널 상단에 상태 설명 버튼을 추가했다.
- 답변 활동 패널 상단에 상태 기준 범례를 고정 노출했다.
- 진행 중, 확인 필요, 완료, 실패, 기록 상태를 같은 배지 UI로 표시하도록 정리했다.
- 진행 단계, 세션 에이전트 실행, 세부 기록의 상태 표시를 같은 기준으로 맞췄다.
- 세부 기록의 raw 영역 명칭을 `원본 이벤트`, `원본 상세 데이터`로 바꿔 개발자 기록임을 더 분명하게 했다.

- 진행 단계, 세션 에이전트 실행, 세부 기록의 상태 배지 표시 확인

## 결정, 이슈, 리스크

- 상태 색상은 실행 주체가 아니라 실행 상태를 나타내도록 유지했다.
- 에이전트 구분은 이름과 배지로 표시하는 방향을 유지한다.
- 내부 raw 이벤트는 일반 상태 요약과 분리해 원본 기록으로 보이도록 명칭을 조정했다.
