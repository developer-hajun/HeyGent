## 작업 목적

- 세션 에이전트 라우팅 후보 프롬프트에서 스킬 사용 예시가 과하게 주입되는 문제를 줄인다.
- 기본 제공 에이전트의 할 수 있는 일 설명을 라우팅 기준으로 더 명확하게 만든다.

## 변경 요약

- 세션 에이전트 후보 payload에서 스킬 `When to use` 발췌 주입을 제거했다.
- 후보 프롬프트의 스킬 설명은 스킬명과 한 줄 description만 표시하도록 정리했다.
- 여러 세션 에이전트가 같은 스킬을 가질 때 description은 공용 스킬 설명 영역에 한 번만 표시하도록 정리했다.
- 기본 제공 에이전트 description을 담당 업무 범위가 드러나도록 보강했다.
- 사용 예시가 후보 프롬프트에 포함되지 않는 회귀 테스트를 추가했다.
