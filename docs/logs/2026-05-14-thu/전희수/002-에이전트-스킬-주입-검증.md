## 작업 목적

- 기본 제공 에이전트 목록을 라우팅 테스트에 필요한 역할 중심으로 정리한다.
- 세션 에이전트가 맡은 child TaskRun(하위 실행)에도 프로필의 스킬 목록이 실제 프롬프트 catalog 필터로 들어가게 한다.

## 변경 요약

- 기본 제공 에이전트 노출 목록을 개발자, QA, UX 디자이너, K-에이전트로 제한했다.
- 범용 기본 에이전트와 보안 에이전트는 기본 제공 목록과 기본 생성 대상에서 제외했다.
- `session_agent_task`로 생성되는 child TaskRun에 `enabledSkillNames`를 주입하도록 보강했다.
- 템플릿 조회 필터가 DB의 `template_key` 필드를 기준으로 동작하도록 수정했다.
