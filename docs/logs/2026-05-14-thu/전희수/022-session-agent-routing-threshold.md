## 작업 목적

- 팀장 에이전트가 직접 일반 답변으로 끝내기 쉬운 혼합 요청에서도, 세션 에이전트 스킬이 더 맞는 의미 있는 하위 작업을 더 쉽게 위임하도록 라우팅 기준을 낮춘다.

## 변경 요약

- 세션 에이전트 라우팅 기준에서 "현재 실행 에이전트가 먼저 직접 실행 가능성을 검토"하고 "다른 세션 에이전트만 가진 능력"일 때만 호출하던 문구를 제거했다.
- 사용자 요청 전체 또는 의미 있는 하위 작업이 세션 에이전트 skill 이름/설명과 맞고 더 적합하게 처리할 가능성이 있으면 `session_agent_task`를 맡기도록 바꿨다.
- 현재 실행 에이전트가 직접 답할 수 있더라도 위 조건을 만족하면 호출을 우선하도록 명시했다.
- 모델 루프 프롬프트 계약 테스트를 새 라우팅 문구 기준으로 갱신했다.

## 결정, 이슈, 리스크

- 서버 키워드 기반 강제 의도분류는 추가하지 않고, 프롬프트의 세션 에이전트 호출 임계값만 낮췄다.
- 호출 기준이 낮아져 일부 요청에서 세션 에이전트 실행이 늘 수 있다.
