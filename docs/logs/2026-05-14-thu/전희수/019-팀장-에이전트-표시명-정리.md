## 작업 목적

- 사용자에게 보이는 메인 에이전트 명칭을 `CEO`에서 `팀장` 기준으로 정리한다.
- 내부 실행 식별자는 유지하면서 UI, 기본 제공 에이전트 템플릿, 프롬프트 문구의 노출 표현을 맞춘다.

## 변경 요약

- 기본 메인 에이전트 템플릿의 표시명, 이름, 호칭을 `팀장`으로 변경했다.
- 메인 에이전트 지침 문서와 라우팅 프롬프트의 사용자 노출 문구를 `팀장` 기준으로 정리했다.
- 답변 활동, 단계 진행 표시, 세션 작업면의 사용자 노출 경로 문구를 `팀장` 기준으로 변경했다.
- 작업 컨텍스트 미리보기와 관련 API 문서 요약의 표시 문구를 `팀장` 기준으로 변경했다.
- 내부 작업 담당자 sentinel 값 `CEO`는 기존 데이터와 라우팅 분기를 위해 유지했다.

- `assigneeAgentId="CEO"`와 `ceo` route id는 기존 작업 보드, 실행 분기, 프론트 라우팅 식별자라서 표시명과 분리해 유지한다.
