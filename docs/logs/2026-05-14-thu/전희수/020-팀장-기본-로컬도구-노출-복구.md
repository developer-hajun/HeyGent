## 작업 목적

- 팀장 에이전트에 기본 스킬이 켜진 세션에서 기본 로컬 도구가 빠져 파일 생성 같은 요청을 처리하지 못하는 문제를 수정한다.

## 변경 요약

- 공개 세션의 기본 TaskRun capability 계산이 안전 설정 allowlist가 아니라 실제 agent.loop 기본 toolset을 기준으로 하도록 수정했다.
- WebSocket 경로와 HTTP 세션 메시지 경로 모두 같은 기본 toolset 계산을 사용하게 맞췄다.
- 팀장 스킬이 켜져도 `file`, `terminal`, `browser`, `messaging` toolset이 유지되는 회귀 테스트를 추가했다.

## 결정 / 이슈

- 사용자가 세션 설정에 명시한 `toolsets`는 기존처럼 좁은 권한으로 유지한다.
- 명시 설정이 없는 기본 팀장 실행만 실제 런타임 기본 toolset을 사용한다.
- 브릿지 미연결 상태에서 `write_file` 호출은 `bridge_not_connected`로 차단되는 것을 확인했다.
