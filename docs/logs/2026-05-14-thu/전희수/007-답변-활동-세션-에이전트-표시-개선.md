## 작업 목적

- 답변 활동 패널에서 CEO 부모 실행과 세션 에이전트 하위 실행이 섞여 보이는 문제를 줄입니다.
- 내부 `agent_profile_...` ID 대신 사용자에게 보이는 에이전트 이름으로 실행 주체를 표시합니다.

## 변경 요약

- 부모 TaskRun의 `session_agent_task` 결과에서 연결된 하위 TaskRun ID를 찾아 답변 활동 목록에 포함하도록 했습니다.
- 진행 단계에서 세션 에이전트 위임은 `CEO가 K-에이전트에게 위임`처럼 표시합니다.
- 하위 실행 단계와 세부 기록의 도구 실행 주체를 `K-에이전트가 ... 실행` 형태로 표시합니다.
- `worker 실행 상태` 문구를 `세션 에이전트 실행`으로 바꿨습니다.

## 테스트 / 확인

- `npm run build`
- `docker compose up -d --build frontend`
- 기존 실사용 테스트 세션에서 답변 활동이 2개로 표시되고, 하위 K-에이전트 활동의 세부 기록에 웹 검색과 브라우저 확인이 `K-에이전트가 ... 실행`으로 표시되는 것을 확인했습니다.

## 결정 / 이슈

- 백엔드 기록은 그대로 두고, 프론트 표시 계층에서 연결된 TaskRun과 실행 주체를 해석합니다.
- 부모 최종 답변은 CEO가 정리하지만, 하위 조사 도구 호출은 세션 에이전트 활동으로 분리해 확인할 수 있게 했습니다.
