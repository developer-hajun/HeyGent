## 작업 목적

CEO 라우팅 기준이 에이전트 호출을 과하게 강제하는 표현으로 읽히지 않도록 조정한다.

## 변경 요약

- CEO 지침에서 직접 처리 제한 표현을 제거하고, 독립 작업으로 맡기는 편이 자연스러운 경우에 세션 에이전트 작업으로 분리하도록 바꿨다.
- 런타임 라우팅 지침에서 특정 도구명을 기준으로 한 문장을 제거했다.
- 단순 응답, 맥락 정리, 최종 종합, 분리 실익이 낮은 작업은 CEO가 직접 처리할 수 있다고 명시했다.
- `session_agent_task` 도구 설명도 독립 산출물, 전문 작업, 명확히 분리되는 요청 일부를 맡기는 기준으로 완화했다.

## 결정, 이슈, 리스크

- 라우팅 기준은 `무조건 호출`이 아니라 `후보 확인 후 독립 작업으로 분리할 실익이 있을 때 위임`으로 정리했다.
- 실제 라우팅 안정성은 모델 판단 영향을 받으므로, 추후 반복 테스트에서 과소/과잉 위임 사례를 더 모아야 한다.
