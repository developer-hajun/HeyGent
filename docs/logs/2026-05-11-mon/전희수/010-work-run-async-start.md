# 작업 목적

작업 보드에서 기존 작업을 다시 실행할 때 프론트 요청 제한 시간보다 에이전트 실행 시간이 길어지면 `timeout of 30000ms exceeded`가 발생하는 문제를 수정한다.

# 변경 요약

- 작업 실행 시작 API가 에이전트 실행 완료까지 기다리지 않고 실행 시작 상태를 즉시 반환하도록 변경했다.
- 일반 채팅 메시지 전송 경로는 기존처럼 응답 완료까지 기다리도록 유지했다.
- 백그라운드 실행 중 오류가 발생하면 작업 실행 상태를 실패로 정리하고 세션 실행 가드를 해제하도록 기존 실패 처리 경로를 재사용했다.

- 작업 실행 직후 상세 결과는 비동기 이벤트와 조회 API로 따라와야 한다.
