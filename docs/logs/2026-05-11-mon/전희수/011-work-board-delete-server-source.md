# 작업 목적

작업 보드에서 삭제 후 서버 작업 목록이 비었을 때 로컬 임시 작업 목록이 다시 보이는 문제를 정리한다.

# 변경 요약

- 일반 세션의 작업 보드는 서버 작업 목록만 표시하도록 변경했다.
- 로컬 임시 작업 목록은 아직 서버 세션이 확정되지 않은 대기 세션에서만 사용한다.
- 일반 세션의 `새 작업` 버튼은 로컬 임시 작업이 아니라 서버 작업을 생성하도록 변경했다.
- 작업 삭제 성공/실패 결과를 화면 알림으로 표시하도록 정리했다.
