# 협업 문서 안내

루트 `docs`는 저장소 전반에 걸친 협업 기록을 모아두는 공간입니다.
PR 생성, 의미 있는 `push`, 설계 결정, 인수인계가 생기면 이 폴더를 기준으로 정리합니다.
세부 작성 규칙과 템플릿은 `docs/AGENTS.md`를 기준으로 합니다.

## 폴더 안내

- `logs/`: 날짜와 작성자 기준의 작업 로그
- `decisions/`: 장기 유지가 필요한 설계 결정
- `handoffs/`: 다음 작업자에게 넘길 인수인계 메모

## 기본 경로 예시

```text
docs/
  logs/
    2026-04-24-thu/
      theundergroundt/
        001-orchestrator-구조-정리.md
  decisions/
    2026-04-24-taskrun-용어-고정.md
  handoffs/
    2026-04-24-theundergroundt.md
```
