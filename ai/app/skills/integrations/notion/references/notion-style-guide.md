# Notion 문서 스타일

Write Notion pages like a clean workspace document: simple, readable, and structured. The goal is not decoration; the goal is quick scanning and confident handoff.

## Visual principles

- Use a short title with the actual subject.
- Use `heading_2` for major sections and `heading_3` for subsections.
- Keep paragraphs short.
- Prefer 3-5 bullets for summaries.
- Use dividers between major groups when the page gets long.
- Use callouts sparingly for scope, warnings, test markers, or final recommendations.
- Use bookmarks or source bullets for references.

## Good section order

```text
요약
핵심 판단
상세 내용
비교 또는 표 형식 내용
리스크 / 확인 필요
출처
다음 액션
```

## Tone

- Korean UI/report writing should be direct and plain.
- Avoid over-formal organization-heavy wording.
- Use labels like `요약`, `상세 내용`, `출처`, `다음 액션`.
- Mark live-test artifacts clearly with `테스트용입니다`.

## Density

- One Notion block should hold one idea.
- Do not paste long raw terminal logs or API responses.
- Convert tool output into readable summaries, lists, or short code blocks.
- For tables, prefer a database only when the user will maintain the rows later.
